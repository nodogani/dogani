# dogani

옵시디언 데일리 노트(`261030 금.md`)를 바탕화면 오버레이로 띄우고, 같은 프로그램을 켠 동료에게 실시간(약 1초) 공유합니다.
내 노트만 쓰거나, 동료 노트만 보거나, 둘 다 펼쳐 둘 수 있습니다.

> 개발용 명세(구성·데이터 형식·API·배포 구조)는 [SPEC.md](SPEC.md)

```
[내 PC] 옵시디언 → todo 폴더 ← Dogani (내 노트: 보기·편집 + 공유)  ──HTTP/SSE──▶  Dogani (다른 사람 노트: 읽기 전용) [동료 PC]
```

## 설치

| 방식 | 설치 | 실행 |
|---|---|---|
| exe (Python 불필요, 권장) | `build.bat` 으로 빌드 후 `dist\Dogani\` 폴더째 복사 | `Dogani.exe` |
| 스크립트 (Python 3.10+) | `app\install.bat` | `app\run.bat` |

- 첫 실행 시 todo 폴더 선택 창이 뜹니다. 동료 노트만 볼 거라면 취소해도 됩니다. (`run.bat --dir "D:\Obsidian\Daily" --port 8765 --add 192.168.0.10` 로 지정 가능)
- Windows 방화벽 알림이 뜨면 **허용**해야 동료가 내 노트를 볼 수 있습니다.
- 이전 버전(DoganiServer/DoganiClient) 설정과 자동 실행은 첫 실행 때 자동으로 옮겨집니다. 이전 프로그램은 종료하고 지우세요.

## 업데이트 (자동)

- exe 는 **처음 한 번만** 받으면 됩니다. 켤 때마다 GitHub 에서 새 버전을 확인해 받아서 실행합니다 (디스코드처럼).
- 켜 둔 동안 새 버전이 나오면 트레이 버전 옆에 "(재시작하면 적용)" 이 뜹니다. 알아서 재시작하지 않습니다.
- 배포: GitHub 에 버전 태그(`v26.11.09.01` 형식) push. 커밋·push 만으로는 나가지 않습니다.
- 개발·테스트: 저장소에서 `app\run.bat` 으로 소스 실행. ui 파일 저장 → 창 새로고침, `.py` 저장 → 자동 재시작. 업데이트는 안 받습니다.
- exe 를 다시 빌드해야 할 때: 새 외부 라이브러리 추가(`app\deps.py`) / `app\launcher.py` 수정.

## 사용법

**화면** — 네비게이션 바 하나 + 할일 창 + 달력 창
- 바: `[● 이름 ▾]  ‹ 261109 월 › 오늘  [할일] [달력]`. 드래그로 이동. 날짜 이동은 할일 창이 열려 있을 때만 보임
- 이름 ▾ = 공간 메뉴 (노션 사이드바처럼)
  - **공용**: 팀 공용 공간 (공용 할일 노트 + 공용 일정, 팀원 모두 편집)
  - **개인**: 나 / 팀원들(팀에 들어오면 자동으로 목록에 나옴, 읽기 전용) / 주소로 추가한 사람
  - 아래: 내 이름 바꾸기, 주소로 노트 추가
- 할일·달력 창은 지금 고른 공간을 보여줌. 창 위쪽 막대를 끌어서 이동, 오른쪽 아래 모서리로 크기 조절 (위치·크기 기억)
- 할일 창 위쪽 막대 = 완료/전체 진행 막대. 달력 창: 날짜별 `완료/전체`, 날짜 클릭 → 할일 창이 그 날짜로
- 달력 창 `일정 편집` = 그 공간의 일정 파일(`2026일정.md` / 공용 `일정.md`)을 바로 편집
- 개인 공간 달력에는 공용 일정도 같이 표시 (점선 테두리). 공용 `==쉬는 날==` 은 화살표 이동에서도 건너뜀
- 연결 점: 초록 = 접속 중, 주황 = 상대가 공유 일시 중지, 빨강 = 차단됨/팀원 전용/다시 로그인 필요, 회색 = 연결 끊김

**팀스페이스** (사내망 전용, 외부망 고려 안 함)
- 팀원 중 한 명의 PC 가 **팀 호스트**가 됨 (트레이 > 팀스페이스 > 이 PC 를 팀 호스트로). 켜 두는 시간이 긴 PC 추천
  - 공용 노트·일정은 호스트 PC 의 `%APPDATA%\Dogani\team\notes` 에 평범한 md 파일로 저장 → 옵시디언으로 열기·백업(폴더 복사) 가능
  - 호스트가 꺼져 있으면 공용 공간만 안 보이고, 내 노트·팀원 노트 보기는 그대로 됨
- 관리자: 트레이 > 팀스페이스 > **새 팀원 초대장 만들기** → 주소와 초대장 코드가 복사됨 → 메신저로 그 사람에게 보내기 (사람마다 하나, 15분 안에 한 번만)
- 팀원: 트레이 > 팀스페이스 > 팀 참여 → **호스트 주소 + 초대장 코드** (팀에서 쓰는 이름 = 트레이의 "내 이름", 처음엔 PC 이름)
  - 한 번 들어오면 이 PC 는 다시 묻지 않음
  - PC 를 바꿈 → 관리자가 트레이 > 팀원 > 그 사람 > 다시 초대 → 새 PC 에서 팀 참여 (이름은 팀에 있던 그대로, 예전 PC 는 로그아웃)
- 관리자(호스트 PC) 트레이: 초대장 만들기·관리(복사·폐기) / 팀원 목록(다시 초대, 내보내기) / 팀 이름 / 공용 폴더 열기
- **팀원에게만 공유** (기본 켜짐): 팀에 들어 있으면 내 노트는 팀원만 볼 수 있음. 팀원은 토큰을 각자 검증해서 호스트가 꺼져 있어도 동작
- 내 이름은 트레이 > 내 이름 또는 공간 메뉴에서 변경. 팀원 목록·접속자 목록에 이 이름이 보임

**트레이 메뉴**
- Dogani 표시 (트레이 아이콘 클릭으로도 전환)
- 내 이름 ▸ 이름 바꾸기 / 팀스페이스 ▸ (위 참고)
- 내 노트 공유 중 ▸ 내 주소(클릭 시 복사) / 공유 일시 중지 / 팀원에게만 공유 / 접속자(이름·IP, 연결 끊고 차단 · 차단 해제)
- todo 경로 ▸ 폴더 열기 / 찾아보기...
- 주소로 추가한 노트 ▸ 보기·삭제 / 추가... (팀원이 아닌 사람)
- 바탕화면에 고정(Win+D에도 남음) · 항상 위에 표시 / 투명도 / 다크 테마 / Windows 시작 시 자동 실행 / 종료
- 아이콘 색: 초록 = 공유 중, 주황 = 공유 일시 중지, 회색 = 포트 사용 중이라 공유 불가

**편집** (내 노트·공용 노트·일정 파일. 옵시디언 라이브 프리뷰 방식 — 옵시디언과 같은 CodeMirror 6 편집기)
- 노트 전체가 편집기 하나. 커서가 닿은 서식만 원문 기호(`**`, `==`, `[[ ]]`, `#` …)가 보이고 나머지는 렌더링
- 0.7초 멈추면 자동 저장 (Ctrl+S 즉시) · Ctrl+Z / Ctrl+Y 실행 취소·다시 실행 (노트 전체)
- 체크박스 클릭 = 완료/해제 (바로 저장)
- Enter: 목록·체크박스 이어 쓰기 (빈 항목에서 Enter = 목록 끝) · Tab / Shift+Tab: 목록 들여쓰기
- 여러 줄 선택·붙여넣기·한글 입력은 일반 편집기와 같음. 표는 클릭하면 원문으로
- 링크는 클릭하면 열림 (맨 URL 은 Ctrl+클릭)
- 노트 영역 밖 클릭 / Esc / 다른 창으로 전환 → 편집 끝
- 편집기 소스는 `app/editor/src/main.js`, 고친 뒤 `app/editor/build.bat` (Node.js 필요, 개발 때만) → `app/ui/vendor/editor.js`
- 노트가 없는 날짜는 클릭하면 `선택폴더/yyyy.mm/YYMMDD 요일.md` 로 새로 만듦
- 옵시디언에서 동시에 고쳐 충돌하면 저장하지 않고 알림

## API (Dogani 전용)

모든 요청에 `X-Dogani-Key` 헤더가 있어야 하며, 없으면(웹브라우저 등) 403입니다. 팀원이면 `X-Dogani-Token`(팀 토큰), `X-Dogani-User`(이름, URL 인코딩)도 붙습니다.

| 경로 | 설명 |
|---|---|
| `GET /api/info` | 이름, PC 이름, 공유 일시 중지 여부, 쓰기 가능 여부 |
| `GET /api/note?date=2026-10-30` | 노트 원문과 완료/전체 개수 |
| `POST /api/note` | `{date, content, base_mtime}` 저장 (같은 PC만) |
| `GET /api/month?ym=2026-10` | 그 달의 날짜별 완료/전체 개수 |
| `GET /api/schedule` · `GET/POST /api/sched-doc` | 일정 목록 · 일정 파일 원문 읽기/저장 |
| `GET /api/events` | SSE. 노트 변경 `changed`, 일정 변경 `schedule`, 일시 중지/재개 `status`, 경로 변경 `reload` |
| `/api/team/...` | 팀 호스트만. `hello`, `join`, `me`(신호 + 팀원 목록), `profile`, 그리고 위와 같은 `note`·`month`·`schedule`·`sched-doc`·`events` (팀원 토큰 필요, 팀원 모두 쓰기 가능) |

설정 파일: `%APPDATA%\Dogani\dogani.json` (환경변수 `DOGANI_HOME` 으로 위치 변경 가능)

> ⚠️ 팀에 들지 않았거나 "팀원에게만 공유"를 끄면 사내망 누구나 내 노트를 볼 수 있습니다(암호 없음). 인증은 사무실 수준(일회용 초대장, 통신 암호화 없음)입니다. 원치 않는 접속자는 트레이에서 차단하고, 잠깐 숨기고 싶을 때는 "공유 일시 중지"를 쓰세요. 일시 중지 중에도 내 오버레이는 그대로 쓸 수 있습니다.
