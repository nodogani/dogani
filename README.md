# Dogani — 사내망 옵시디언 todo 실시간 공유

옵시디언 데일리 노트(`261030 금.md`)를 바탕화면 오버레이로 띄우고, 같은 프로그램을 켠 동료에게 실시간(약 1초) 공유합니다.
프로그램은 **Dogani 하나**입니다. 내 노트만 쓰거나, 동료 노트만 보거나, 둘 다 펼쳐 둘 수 있습니다.

```
[내 PC] 옵시디언 → todo 폴더 ← Dogani (내 노트: 보기·편집 + 공유)  ──HTTP/SSE──▶  Dogani (다른 사람 노트: 읽기 전용) [동료 PC]
```

## 설치

| 방식 | 설치 | 실행 |
|---|---|---|
| exe (Python 불필요, 권장) | `build.bat` 으로 빌드 후 `dist\Dogani\` 폴더째 복사 | `Dogani.exe` |
| 스크립트 (Python 3.10+) | `app\install.bat` | `app\run.bat` |

- 첫 실행 시 todo 폴더 선택 창이 뜹니다. 동료 노트만 볼 거라면 취소해도 됩니다. (`run.bat --dir "D:\Obsidian\Daily" --port 8765 --add 192.168.0.10` 로 지정 가능)
- Windows 방화벽 알림이 뜨면 **허용**해야 동료가 내 노트를 볼 수 있습니다.
- 이전 버전(DoganiServer/DoganiClient) 설정과 자동 실행은 첫 실행 때 자동으로 옮겨집니다. 이전 프로그램은 종료하고 지우세요.

## 사용법

**트레이 메뉴**
- 내 노트 표시 (트레이 아이콘 클릭으로도 전환)
- 내 노트 공유 중 ▸ 내 주소(클릭 시 복사) / 공유 일시 중지 / 접속 IP(● 접속 중, PC 이름, 연결 끊고 차단 · 차단 해제)
- todo 경로 ▸ 폴더 열기 / 찾아보기...
- 다른 사람 노트 ▸ 주소별 표시·삭제 / 추가...
- 바탕화면에 고정(Win+D에도 남음) · 항상 위에 표시 / 투명도 / 다크 테마 / Windows 시작 시 자동 실행 / 종료
- 아이콘 색: 초록 = 공유 중, 주황 = 공유 일시 중지, 회색 = 포트 사용 중이라 공유 불가

**오버레이** (내 노트 하나 + 추가한 사람마다 하나씩, 각각 따로 이동·펼치기)
- 네비게이션 바(● 이름, 노트 버튼, 달력 버튼)를 드래그해서 이동. 다른 사람 바에는 상대 PC 이름 표시
- 연결 점: 초록 = 접속 중, 주황 = 상대가 공유 일시 중지, 빨강 = 차단됨, 회색 = 연결 끊김
- 노트 버튼: 오늘의 노트. `‹ ›` 로 날짜 이동, `오늘` 로 복귀. 위쪽 진행 막대 = 완료/전체
- 달력 버튼: 날짜별 `완료/전체` 표시, 날짜 클릭 시 해당 노트로 이동
- 오른쪽 아래 모서리를 드래그해서 패널 크기 조절 (위치·크기 기억)

**내 노트 편집** (옵시디언 라이브 프리뷰 방식)
- 줄을 클릭하면 그 줄만 원문(`- [ ] ...`)으로 바뀌고 나머지는 그대로. 0.7초 멈추면 자동 저장 (Ctrl+S 즉시)
- 체크박스 클릭 = 완료/해제
- Enter: 목록·체크박스 이어 쓰기 (빈 항목에서 Enter = 들여쓰기 빼기/목록 끝) · Shift+Enter: 기호 없이 줄바꿈
- Tab / Shift+Tab: 목록 들여쓰기 · ↑↓: 옆 줄로 이동 · 줄 맨 앞 Backspace: 윗줄과 합치기
- 코드블록·표·속성(frontmatter)은 덩어리째 편집
- 노트 영역 밖 클릭 / Esc / 다른 창으로 전환 → 편집 끝
- 노트가 없는 날짜는 클릭하면 `선택폴더/yyyy.mm/YYMMDD 요일.md` 로 새로 만듦
- 옵시디언에서 동시에 고쳐 충돌하면 저장하지 않고 알림

## API (Dogani 전용)

모든 요청에 `X-Dogani-Key` 헤더가 있어야 하며, 없으면(웹브라우저 등) 403입니다. 쓰기는 같은 PC에서 온 요청만 허용합니다.

| 경로 | 설명 |
|---|---|
| `GET /api/info` | 이름(PC 이름), 공유 일시 중지 여부, 쓰기 가능 여부 |
| `GET /api/note?date=2026-10-30` | 노트 원문과 완료/전체 개수 |
| `POST /api/note` | `{date, content, base_mtime}` 저장 (같은 PC만) |
| `GET /api/month?ym=2026-10` | 그 달의 날짜별 완료/전체 개수 |
| `GET /api/events` | SSE. 노트 변경 `changed`, 일시 중지/재개 `status`, 경로 변경 `reload` |

설정 파일: `%APPDATA%\Dogani\dogani.json` (환경변수 `DOGANI_HOME` 으로 위치 변경 가능)

> ⚠️ Dogani 가 있으면 사내망 누구나 내 노트를 볼 수 있습니다(암호 없음). 원치 않는 접속자는 트레이에서 차단하고, 잠깐 숨기고 싶을 때는 "공유 일시 중지"를 쓰세요. 일시 중지 중에도 내 오버레이는 그대로 쓸 수 있습니다.
