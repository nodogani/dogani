# dogani

폴더 하나(**볼트**)의 데일리 노트(`261030 금.md`)와 일정 파일을 바탕화면 오버레이로 띄웁니다.
팀원끼리는 **팀 볼트**(팀 호스트 PC 의 폴더)를 실시간(약 1초)으로 같이 보고 편집합니다.

> 개발용 명세(구성·데이터 형식·API·배포 구조)는 [SPEC.md](SPEC.md)

```
[내 PC]   내 볼트 (이 PC 에서만)        ← dogani
[호스트 PC] 팀 볼트 ──HTTP/SSE──▶ 팀원 PC 의 dogani (팀원 모두 편집)
```

## 설치

| 방식 | 설치 | 실행 |
|---|---|---|
| 설치 파일 (Python 불필요, 권장) | `dogani-setup.exe` 실행 (관리자 권한 불필요, 다시 실행하면 덮어 설치) | 시작 메뉴 `dogani` |
| exe 폴더 | `build.bat` 으로 빌드 후 `dist\dogani\` 폴더째 복사 | `dogani.exe` |
| 스크립트 (Python 3.10+) | `app\install.bat` | `app\run.bat` |

- 첫 실행 시 **볼트 열기**(노트 폴더 선택) 창이 뜹니다. (`run.bat --dir "D:\업무" --port 8765` 로 지정 가능)
- 팀 호스트 PC 는 Windows 방화벽 알림이 뜨면 **허용**해야 팀원이 접속할 수 있습니다.
- 예전 버전의 todo 폴더는 그대로 내 볼트가 되고, 팀 호스트의 공용 노트 폴더는 그대로 팀 볼트가 됩니다 (자동 이전).

## 업데이트 (자동)

- exe 는 **처음 한 번만** 받으면 됩니다. 켤 때마다 GitHub 에서 새 버전을 확인해 받아서 실행합니다 (디스코드처럼).
- 켜 둔 동안에는 업데이트를 확인하지 않습니다. 새 버전은 다음에 켤 때 적용됩니다.
- 배포: GitHub 에 버전 태그(`v26.11.09.01` 형식) push. 커밋·push 만으로는 나가지 않습니다.
- 개발·테스트: 저장소에서 `app\run.bat` 으로 소스 실행. ui 파일 저장 → 창 새로고침, `.py` 저장 → 자동 재시작. 업데이트는 안 받습니다.
- exe 를 다시 빌드해야 할 때: 새 외부 라이브러리 추가(`app\deps.py`) / `app\launcher.py` 수정.

## 사용법

**볼트** — 폴더 하나 = 볼트 하나 (옵시디언처럼)
- 트레이 > 볼트 ▸ 최근 볼트 목록(클릭 = 전환) / 폴더 열기 / **볼트 열기...**
- 볼트 안 어디에 있든 `YYMMDD 요일.md`(또는 `2026-10-30.md`) = 데일리 노트, `2026일정.md`·`일정.md` = 일정 파일
- 새 노트는 `볼트/yyyy.mm/YYMMDD 요일.md` 로 만듦. 업무 자료가 섞여 있는 폴더를 열어도 됨 (다른 파일은 무시)
- 볼트 폴더에 `.dogani/` 가 생김 (볼트 설정). 점(.)으로 시작하는 폴더는 노트로 읽지 않음
- **내 볼트는 남에게 공유되지 않습니다.** 팀원과 같이 볼 것은 팀 볼트에 씁니다

**화면** — 네비게이션 바 하나 + 할일 창 + 달력 창
- 바: `[● 이름 ▾]  ‹ 261109 월 › 오늘  [할일] [달력]`. 드래그로 이동. 날짜 이동은 할일 창이 열려 있을 때만 보임
- 이름 ▾ = 공간 메뉴: **팀 볼트** / **내 볼트** / 내 이름 바꾸기 / 볼트 열기
- 할일·달력 창은 지금 고른 공간을 보여줌. 창 위쪽 막대를 끌어서 이동, 오른쪽 아래 모서리로 크기 조절 (위치·크기 기억)
- 할일 창 위쪽 막대 = 완료/전체 진행 막대. 달력 창: 날짜별 `완료/전체`, 날짜 클릭 → 할일 창이 그 날짜로
- 달력 창 `일정 편집` = 그 공간의 일정 파일을 바로 편집
- 내 볼트 달력에는 팀 일정도 같이 표시 (점선 테두리). 팀 `==쉬는 날==` 은 화살표 이동에서도 건너뜀
- 연결 점: 초록 = 연결됨, 빨강 = 다시 로그인 필요, 회색 = 연결 끊김

**팀 볼트** (사내망 전용, 외부망 고려 안 함)
- 팀원 중 한 명의 PC 가 **팀 호스트**가 됨 (트레이 > 팀스페이스 > 이 PC 를 팀 호스트로 → 팀 볼트 폴더 고르기). 켜 두는 시간이 긴 PC 추천
  - 팀 볼트는 평범한 폴더 (md 파일). 백업 = 폴더 복사. 내 볼트와 겹치는 폴더는 고를 수 없음
  - 호스트가 꺼져 있으면 팀 볼트만 안 보이고, 내 볼트는 그대로 됨
- 관리자: 트레이 > 팀스페이스 > **새 팀원 초대장 만들기** → 주소와 초대장 코드가 복사됨 → 메신저로 그 사람에게 보내기 (사람마다 하나, 15분 안에 한 번만)
- 팀원: 트레이 > 팀스페이스 > 팀 참여 → **호스트 주소 + 초대장 코드** (팀에서 쓰는 이름 = 트레이의 "내 이름", 처음엔 PC 이름)
  - 한 번 들어오면 이 PC 는 다시 묻지 않음
  - PC 를 바꿈 → 관리자가 트레이 > 팀원 > 그 사람 > 다시 초대 → 새 PC 에서 팀 참여 (이름은 팀에 있던 그대로, 예전 PC 는 로그아웃)
- 관리자(호스트 PC) 트레이: 초대장 만들기·관리(복사·폐기) / 팀원 목록(다시 초대, 내보내기) / 팀 이름 / 팀 볼트 폴더 열기
- 호스트 옮기기: 팀 볼트 폴더 + `%APPDATA%\dogani\team\<볼트id>.json`(서명 키) 을 새 PC 로 복사 → 새 PC 에서 호스트 켜기

**트레이 메뉴**
- dogani 표시 (트레이 아이콘 클릭으로도 전환)
- 내 이름 ▸ 이름 바꾸기 / 팀스페이스 ▸ (위 참고) / 볼트 ▸ (위 참고)
- 바탕화면에 고정(Win+D에도 남음) · 항상 위에 표시 / 투명도 / 다크 테마 / Windows 시작 시 자동 실행 / 종료
- 아이콘 색: 초록 = 동작 중, 회색 = 포트 사용 중이라 볼트를 열 수 없음

**편집** (내 볼트·팀 볼트 노트·일정 파일. CodeMirror 6 라이브 프리뷰, 옵시디언과 같은 방식)
- 노트 전체가 편집기 하나. 커서가 닿은 서식만 원문 기호(`**`, `==`, `[[ ]]`, `#` …)가 보이고 나머지는 렌더링
- 0.7초 멈추면 자동 저장 (Ctrl+S 즉시) · Ctrl+Z / Ctrl+Y 실행 취소·다시 실행 (노트 전체)
- 체크박스 클릭 = 완료/해제 (바로 저장)
- Enter: 목록·체크박스 이어 쓰기 (빈 항목에서 Enter = 목록 끝) · Tab / Shift+Tab: 목록 들여쓰기
- 여러 줄 선택·붙여넣기·한글 입력은 일반 편집기와 같음. 표는 클릭하면 원문으로
- 링크는 클릭하면 열림 (맨 URL 은 Ctrl+클릭)
- 노트 영역 밖 클릭 / Esc / 다른 창으로 전환 → 편집 끝
- 편집기 소스는 `app/editor/src/main.js`, 고친 뒤 `app/editor/build.bat` (Node.js 필요, 개발 때만) → `app/ui/vendor/editor.js`
- 다른 편집기(옵시디언 등)에서 동시에 고쳐 충돌하면 저장하지 않고 알림

설정 파일: `%APPDATA%\dogani\dogani.json` (환경변수 `DOGANI_HOME` 으로 위치 변경 가능)

> ⚠️ 인증은 사무실 수준(일회용 초대장, 통신 암호화 없음)입니다. 팀 볼트는 팀원 모두가 읽고 고칠 수 있습니다.
