# TodoShare — 사내망 옵시디언 todo 실시간 공유

옵시디언 데일리 노트(`261030 금.md`)를 동료 PC 바탕화면 오버레이로 실시간(약 1초) 공유합니다. 클라이언트는 읽기 전용입니다.

```
[내 PC] 옵시디언 → todo 폴더 ← todo_server.py (트레이)  ──HTTP/SSE──▶  todo_client.py (트레이 + 바탕화면 오버레이) [동료 PC]
```

## 설치

### exe (Python 설치 불필요, 권장)

`build.bat` 으로 빌드한 뒤 폴더째 복사합니다.

| 구분 | 복사할 폴더 | 실행 |
|---|---|---|
| 서버 (노트 작성자 PC) | `dist\TodoShareServer\` | `TodoShareServer.exe` |
| 클라이언트 (보는 사람 PC) | `dist\TodoShareClient\` | `TodoShareClient.exe` |

### 스크립트 (Python 3.10+ 필요)

| 구분 | 설치 | 실행 |
|---|---|---|
| 서버 (노트 작성자 PC) | `server\install.bat` | `server\run_server.bat` |
| 클라이언트 (보는 사람 PC) | `client\install.bat` | `client\run_client.bat` |

- 서버 첫 실행 시 todo 폴더 선택 창이 뜹니다. (`run_server.bat --dir "D:\Obsidian\Daily" --port 8765` 로 지정 가능)
- Windows 방화벽 알림이 뜨면 **허용**해야 동료가 접속할 수 있습니다.
- 클라이언트 첫 실행 시 서버 주소(예: `192.168.0.10` 또는 `192.168.0.10:8765`)를 입력합니다. 서버 주소는 서버 트레이 > 서버 실행 중 > 주소 클릭으로 복사됩니다.

## 사용법

**서버 트레이**: 서버 실행 중(주소 복사) / 공유 일시 중지 / 접속 IP(● 접속 중, PC 이름, 연결 끊고 차단 · 차단 해제) / todo 경로(폴더 열기, 찾아보기...) / Windows 시작 시 자동 실행 / 서버 종료

**클라이언트 트레이**: 서버 접속 중·연결 끊김(접속 서버 변경...) / 오버레이 표시(트레이 아이콘 클릭으로도 전환) / 바탕화면에 고정(Win+D에도 남음) · 항상 위에 표시 / 투명도 / 다크 테마 / Windows 시작 시 자동 실행 / 종료

**오버레이**
- 네비게이션 바(● 서버IP, 노트 버튼, 달력 버튼)를 드래그해서 이동
- 연결 점: 초록 = 접속 중, 주황 = 서버가 공유 일시 중지, 빨강 = 차단됨, 회색 = 연결 끊김
- 노트 버튼: 오늘의 노트 (아직 없으면 가장 최근 노트). `‹ ›` 로 날짜 이동, `오늘` 로 복귀. 위쪽 진행 막대 = 완료/전체
- 달력 버튼: 날짜별 `완료/전체` 표시, 날짜 클릭 시 해당 노트로 이동
- 오른쪽 아래 모서리를 드래그해서 패널 크기 조절 (위치·크기 기억)

## API (읽기 전용, 클라이언트 전용)

모든 요청에 `X-TodoShare-Key` 헤더가 있어야 하며, 없으면(웹브라우저 등) 403입니다.

| 경로 | 설명 |
|---|---|
| `GET /api/note?date=2026-10-30[&fallback=1]` | 노트 원문과 완료/전체 개수 (fallback: 없으면 이전 최근 노트) |
| `GET /api/month?ym=2026-10` | 그 달의 날짜별 완료/전체 개수 |
| `GET /api/events` | SSE. 노트 변경 `changed`, 일시 중지/재개 `status` |

설정 파일: `%APPDATA%\TodoShare\server.json`, `client.json` (환경변수 `TODOSHARE_HOME` 으로 위치 변경 가능)

> ⚠️ 클라이언트 프로그램이 있으면 사내망 누구나 접속할 수 있습니다(암호 없음). 원치 않는 접속자는 서버 트레이에서 차단하고, 잠깐 숨기고 싶을 때는 "공유 일시 중지"를 쓰세요.
